## 4. 失败处理

- 提交超时：先查询供应商任务，不重复提交。
- 适配器参数不符：停止真实调用，记录差异并修复合约测试。
- 任务失败：保留额度记录；是否重试需重新批准。
- 返回成功：只代表 L3 API 成功，仍需 L4 人工质量验收。
