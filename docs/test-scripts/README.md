# 测试剧本模板与 Fixtures

本目录提供三类可填写的空白剧本模板，以及用于自动化测试的非空短剧本。

## 空白模板

| 模板 | Markdown | Word | 用途 |
| --- | --- | --- | --- |
| A：室内双人对话 | `A-室内双人对话-template.md` | `A-室内双人对话-template.docx` | 两人对白、情绪、简单动作、镜头切换 |
| B：都市多场景 | `B-都市多场景-template.md` | `B-都市多场景-template.docx` | 多地点、多角色、时间/服装/道具变化 |
| C：单人悬疑 | `C-单人悬疑-template.md` | `C-单人悬疑-template.docx` | 单人、少对白、画外音、特写、道具与悬念 |

模板是“可直接填写”的空白结构，不包含完整固定剧情。请复制后再填写，不要直接拿空白模板做 AI 解析质量验收。

## Fixtures

`fixtures/` 下是三份非空短剧本，仅用于解析、分镜和纵向 Mock 验收：

- `A-室内双人对话.md`
- `B-都市多场景.md`
- `C-单人悬疑.md`

Fixtures 不替代真实用户剧本，也不用于验证模型对任意题材的泛化能力。

## 建议验收顺序

1. 用 Fixture A/B/C 验证上传、解析、审核、场次和分镜链路。
2. 用空白模板让用户填写实际项目内容。
3. Mock 模型结果完成视频批量与导出。
4. 真实供应商测试必须单独审批并受额度门禁控制。
