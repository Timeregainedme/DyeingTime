# Fixture B：都市多场景

项目：雨夜订单
风格：都市悬疑
角色：程野（外卖员）、许棠（花店店主）、老赵（保安）
场景一：花店门口，雨夜，霓虹反光
场景二：写字楼大堂，深夜，冷白灯
场景三：地下车库，凌晨，灯光闪烁

程野把最后一束花送到花店。许棠没有接花，只递给他一个没有寄件人的信封。

许棠：订单备注说，送到地下车库 B3。
程野：你确定？
许棠：他说你会认识的。

写字楼大堂里，老赵拦住程野，看到他手里的信封后沉默片刻，按下了电梯按钮。

老赵：B3 今天没有监控。
程野：那我更应该下去。

地下车库，程野找到一扇半开的卷帘门。门内桌上放着同样的花束，包装上写着许棠的名字。他回头，电梯数字正在向下跳动。
